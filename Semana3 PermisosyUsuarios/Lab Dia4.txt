Laboratorio Dia 4
Segun los requerimientos de este laboratorio se deben hacer pruebas con los comandos chown y el chgrp

1.- Se modificaran el owner y el grupo de los directorios BodegaCod y BodegaDoc al usuario/grupo  Karen/Bodega
  - sudo chown Karen BodegaCod ------ Este comando cambia el owner del directorio de root a Karen
  - sudo chown Karen BodegaDoc ------ Este comando cambia el owner del directorio de root a Karen
  - sudo chgrp Bodega BodegaCod ------ Este comando cambia el grupo del directorio de root a Bodega
  - sudo chgrp Bodega BodegaDoc ------ Este comando cambia el grupo del directorio de root a Bodega
2.- Se modificaron el owner y el grupo del directorio EscuelaCod al usuario/grupo  Samara/Escuela
  - sudo chown Samara EscuelaCod ------ Este comando cambia el owner del directorio de root a Samara
  - sudo chgrp Escuela Escuela Cod ------ Este comando cambia el grupo del directorio de root a EScuela
3.- Se modificaron el owner y el grupo del directorio EscuelaDoc al usuario/grupo Dante/Escuela
  - sudo chown Dante EscuelaDoc ----- ESte comando cambia el owner del directorio de root a Dante
  - sudo chgrp Escuela EscuelaDoc ----- Este comando cambia el grupo del directorio de root a Escuela


En adicion se modificaron los permisos de los directorios asignados al grupo Bodega con el siguiente comando
  - sudo chmod 760 BodegaCod
  - sudo chmod 760 BodegaDoc
Estos comandos se dejaron con la siguiente finalidad
  1.- 7: Al owner del directorio se le da completo permisos sobre el directorio
  2.- 6: Al grupo se le asignaron los permisos de escritura y lectura sobre el directorio
  3.- 0: Al cualquiera no sea el owner o pertenezca al grupo, no tiene ningun permiso sobre dicho directorio
