Se realiza la prueba y utilizacion de los comandos a continuacion
- PWD: Comando para saber la ruta actual donde se encuentra uno ubicado
- CD: Comando se utiliza para cambiar a la ruta deseada
- ls: se utiliza para listar los archivos o carpetas que se encuentren en la ruta actual, dependiendo de como se utilice segun indice, puede traer mayor informacion
- clear: comando para limpiar la terminal de lo realizado anteriomente
- history: Muestra por pantalla todos los comandos utilizados anteriomente
- man [comando]: este comando se utiliza para consultar el manual y todo lo relacionado con el comando a consultar
      Ejemplo: man ls: Se obtiene todo el manual del comando ls
