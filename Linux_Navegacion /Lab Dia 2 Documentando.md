Se efectua la documentacion de lo efectuado durante el Laboratio 2 

Se utilizan los siguientes comandos

- sudo: permite pasar a la terminal a usuario root
- touch: permite crear archivos vacios dentro la rama raiz o donde uno se encuentre
- mkdir: permite la creacion de directorios SIEMPRE Y CUANDO se encuentren en usuario root o no se podra realizar esta accion
- cp: permite copiar archivos anteriomente existentes
- mv: permite mover archivos de una carpeta a otra
- rm: permite remover archivos o directorios dependiendo como se invoque el comando 
- file: permite consultar la data dentro del archivo
